### 启动方式（有两个坑）

1. **必须清掉 `ELECTRON_RUN_AS_NODE=1`。** DSH 的 shell 环境里带这个变量，直接执行
   `/Applications/Cursor.app/Contents/MacOS/Cursor --user-data-dir=...` 会变成 Node
   解释器（报 `bad option: --user-data-dir`，`--version` 打印 `v24.19.0`）。
2. **必须 `--no-sandbox --disable-gpu`。** 在 DSH 文件沙箱里 Chromium 子进程建 sandbox 失败
   （`sandbox initialization failed: Operation not permitted`），GPU 进程反复退出后主进程
   `FATAL ... GPU process isn't usable. Goodbye.` 直接崩。

实际使用的命令（作为后台 job 运行，避免被回收）：

```bash
cd /Users/lyaqanyi/Documents/GitHub/sessionport
exec env -u ELECTRON_RUN_AS_NODE \
  "/Applications/Cursor.app/Contents/MacOS/Cursor" \
  --user-data-dir="$PWD/.tmp/cursor-app-test" \
  --remote-debugging-port=9223 \
  --no-sandbox --disable-gpu --disable-gpu-sandbox --disable-dev-shm-usage
```

额外加了 `--remote-debugging-port=9223`（任务建议里没有）：这样可以用 CDP 读 DOM/截图，
证据比纯像素截图更硬。CDP 页面目标是 `vscode-file://.../workbench`，标题 `Cursor Agents`
——3.27 的会话界面在 **Agents 窗口**（`CURSOR_LAYOUT=glass`），不是 IDE 面板。
日志：`.tmp/cursor-ui/cursor.log`（第一次）、`.tmp/cursor-ui/cursor-run2.log`（本次），
辅助脚本 `.tmp/cursor-ui/cdp.mjs`（eval/evalfile/shot/size）。

⚠️ **3.27 的 AgentStores 不走 `--user-data-dir`**：运行中弹出错误
`Failed to save 'beta-draw-100.json' … /Users/lyaqanyi/Library/Application Support/Cursor/AgentStores/cursor_agent_stores/…`
（EPERM）。路径写死在真实库目录下；本次因为 DSH 沙箱拦住，**没有真的写进用户库**
（已核对：`AgentStores/cursor_agent_stores/*` 的 mtime 仍是 10-23/10-30 09:30，本次测试期间未变）。
含义：在无沙箱的真实机器上，用副本库起 3.27 会**反向写用户真实库**，这不是"完全隔离"。

## 5. 卡点 / 无法判断的项

1. **"展开后才可见"是否等于"通过"需要产品口径**：结构校验管不到"默认展开"，本次证明的是
   *卡片能正确渲染*，不证明*默认可见*。若验收要求"打开即见工具卡"，3.27 不满足，但原生会话同样不满足。
2. **grep 卡片在本会话缺席**（源会话 0 次 ripgrep），只用另一个小会话旁证，未覆盖"大量 grep"的场景。
3. **read 卡片正文永远为空**：writer 不伪造文件内容，UI 里 read 行点开也没有正文——与原生一致，
   但"read 卡片显示文件内容"这类验收项无法通过。
4. **checkpoint / 打开文件**：writer 未写 before/after 内容 blob，edit 卡片可看 diff，但卡片上的
   "在文件中打开/diff 视图"类操作在本会话里未逐一试（时间不够，且需要工作区真实文件在位）。
5. **原生 import 对照未做完**：只验证了"原生 composer 同样折叠"这一点（`8b130de0`），
   没有跑完整对照矩阵（原生 vs 导入在分组边界上的差异）。
6. **3.27 AgentStores 反写真实库**：本次被沙箱拦住。要在真机上复现"副本库 + 3.27"，必须先备份
   `~/Library/Application Support/Cursor/AgentStores`。
